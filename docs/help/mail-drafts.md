## Steps
1. Open Mail and choose the Drafts tab. You see drafts only for your own mailboxes, and for shared mailboxes if you are a superadmin.
2. Each row shows the contact, the mailbox, when it was drafted and its status.
3. Approve opens the draft in Gmail in a new tab. Read it there and press Send in Gmail yourself.
4. Edit opens the same draft in Gmail for you to change before you send it.
5. Reject deletes the draft from Gmail.
6. A row marked Needs a person is a question the Hub will not draft: anything clinical, legal, about money or refunds, or possible crisis language. Answer it yourself, then Dismiss it.

## Common mistakes
- The Hub never sends an email. A draft sits in Gmail until you send it there.
- The draft's words live only in Gmail. The Hub keeps a pointer to the draft and, after you send it, one short sentence about what you changed, which it uses to write closer to your style next time.
- Thank-you notes, our own replies and automated notices never get a draft.
- Drafting is off until it is turned on for the organization. While it is off, the Drafts tab says so.
