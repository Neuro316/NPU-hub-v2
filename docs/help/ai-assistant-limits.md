## Steps
1. Open CRM Settings and find the Campaign sending section.
2. Under Switches, tick Campaign Builder or Hub Guide to switch either on for this organization. Both start switched off.
3. In AI assistants, read this month's spend for each, then set each monthly limit in US dollars.
4. Set how many messages one conversation may hold and how many steps one Campaign Builder run may take.
5. Under Who may use the Hub Guide, tick the roles that should see it. The Campaign Builder is always for platform superadmins only.
6. Press Save limits.

## Common mistakes
- Only a platform superadmin sees the AI assistants section and can change the switches.
- When a monthly limit is reached, that assistant stops for the rest of the month and says so. Raise the limit here to continue.
- A limit of 0 stops that assistant entirely, which is different from switching it off: the switch hides it, the limit refuses its requests.
